# Contributing

Do not submit private financial, tax, identity, bank, brokerage, or billing data.

## Allowed Contributions

- Synthetic fixtures.
- Generic parser adapters.
- Documentation.
- Security test cases.
- CI improvements.
- Public library research.

## Required For Parser Contributions

- License review.
- Offline behavior documented.
- Network behavior documented.
- Tests using synthetic fixtures.
- Provenance output documented.

## Pull Request Requirements

- Explain the synthetic fixture used.
- Explain what source citation metadata is produced.
- Include validation commands.
- State whether the code can run fully offline.
- State whether the dependency has native binaries or model downloads.
- Keep examples generic and public-safe.
